# One Line, One Laugh — "The Smoke Detector's Reminder"

One funny line of 95 characters, written for the [make.fun bounty "One Line, One Laugh"](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea).

> My smoke detector has never detected smoke. It just beeps at 3 AM to remind me it still exists.

`main.py` writes that single line to `/output/entry.txt` (UTF-8, one line, 1–200 characters),
where the sealed scorer reads it. The program also reads the file back and asserts it is
exactly one line with the same content.
